## 🚀 Tecnologías Utilizadas

El proyecto fue construido utilizando el ecosistema de **Vue 3** y herramientas de alto rendimiento:

* **Framework:** [Vue 3](https://vuejs.org/) (Composition API con `<script setup>`)
* **Lenguaje:** [TypeScript](https://www.typescriptlang.org/) para un desarrollo robusto y tipado
* **Herramienta de Construcción:** [Vite](https://vitejs.dev/) para recarga rápida en desarrollo y optimización para producción
* **Estilos:** CSS moderno con arquitectura de variables personalizadas para temas visuales
* **Interactividad:** Integración de diseños 3D mediante Spline

---

## ✨ Características Principales

* **Diseño Futurista:** Inclusión de un modelo 3D interactivo (Robot) en la sección Hero
* **Lógica Desacoplada:** Uso de Vue Composables (`useNavigation`, `useTechnologies`) para separar la lógica de negocio de la interfaz
* **Experiencia de Usuario:** Implementación de componentes de carga (Skeleton Screens) y notificaciones interactivas (Toasts)
* **Timeline de Experiencia:** Visualización cronológica de mi trayectoria profesional

---

## 🛠️ Estructura del Proyecto

La aplicación sigue una arquitectura modular y escalable:

* **`/src/sections`** — Secciones principales de la página única (Hero, TechStack, Experience)
* **`/src/common`** — Composables y tipos compartidos para la lógica de navegación y tecnologías
* **`/src/components`** — Componentes de UI reutilizables y formularios de contacto
* **`/src/layouts`** — Estructura base de la página (Header y Footer)

## 📦 Instalación y Configuración

Para ejecutar el proyecto localmente:

### 1️⃣ Clonar el repositorio

```bash
git clone https://github.com/danielatarapues/portafolio-vue.git
```

### 2️⃣ Instalar dependencias

```bash
npm install
```

### 3️⃣ Ejecutar en modo desarrollo

```bash
npm run dev
```

### 4️⃣ Construir para producción

```bash
npm run build
```
